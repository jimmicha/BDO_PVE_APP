# Black Desert Online PvE Gear Stats Database
# Verified for current guides/patch state on 2026-09-08.
# Format: pipe-delimited UTF-8 text. First non-comment line is the column header.
#
# IMPORTANT FIELD DEFINITIONS
# ap_min/ap_max      = AP range printed on weapon item.
# sheet_ap           = single displayed AP value on accessories/reform bonuses.
# sheet_dp           = displayed DP.
# monster_ap         = Extra AP Against Monsters; this is NOT sheet AP.
# monster_dr         = Monster Damage Reduction; this is NOT sheet DP.
# evasion / damage_reduction = visible component.
# hidden_evasion / hidden_damage_reduction = value shown in parentheses by current item stat tables.
# delta_*            = increase from the previous enhancement of the SAME item/variant.
# blank               = stat not supplied/not applicable, NOT zero.
#
# SCOPE
# This file is the enhancement data for the current PvE progression systems:
# Sovereign weapons, Slumbering Origin armors, Edana armors,
# Kharazad/Ekleta/Apeiron accessories, and PvE artifacts.
# Legacy/transitional full Tuvala and Blackstar +0..PEN ladders are intentionally
# not mixed into this endgame table because the modern 2026 catch-up path skips
# most of those enhancement steps. PEN Blackstar is a Sovereign crafting gateway.
#
# SET EFFECT NOTE
# Slumbering Origin / Edana 'Ancient' set effects are account/equipment-set effects,
# not per-piece AP/DP and therefore are not added to individual rows.
# Relevant set effects include 2-set Monster DR +10 and 3-set Extra Monster AP +7.
